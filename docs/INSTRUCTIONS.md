# YourStyle POS Staff Guide

## Dashboard

The Dashboard gives you a quick view of the store's inventory, deliveries, returns, and sales.

## How to open the Dashboard

1. Sign in to YourStyle POS.
2. Select **Dashboard** from the left menu.
3. Wait for the page to finish loading.

If the page does not load, select **Retry**.

## How to change the date

1. Select the date button at the top-right of the Dashboard.
2. Choose a date or date range.
3. Select **Apply**.

You can also use these quick choices:

- Today
- Yesterday
- This week
- This month
- This year
- Last week
- Last month

Cashiers can only view today's sales. Managers and OICs can view previous dates.

## What you can see on the Dashboard

### Inventory

The Inventory card shows:

- Total items currently in stock.
- Number of low-stock products.

Select the **Inventory card** to see the full inventory summary.

Select the **bell icon** to see items that need attention:

- **Incomplete** — item information is not yet complete.
- **Sold out** — item has no stock left.
- **Low stock** — item is near its minimum stock level.
- **Undistributed** — wholesale items still need to be distributed.

Select any reminder to open the related items on the Inventory page.

> The Inventory card always shows the current stock, even if you select an older date.

### Delivery

The Delivery card shows:

- Number of deliveries received during the selected date.
- Number of deliveries that are still incomplete.

Select the **Delivery card** to see the items received. Select the **arrow icon** to open the Deliveries page.

### Return

The Return card shows:

- Number of supplier returns during the selected date.
- Total number of items returned.

Select the **Return card** to see the returned items. Select the **arrow icon** to open the Supplier Returns page.

### Net sales

This shows the total sales after discounts and returns.

Select the **Net sales card** to see sales for each date. You can view the sales by:

- Payment method
- Cashier — managers and OICs only

### Units sold

This shows the total number of items sold during the selected date.

Select the **Units sold card** to see:

- Item description
- Price
- Quantity sold
- Total sales per item

### Transactions

This shows the number of completed checkouts or receipts.

Select the **Transactions card** to see:

- Transactions per date
- Average sale
- Total sales
- Sales per cashier — managers and OICs only

### Sales and units sold graph

The graph shows:

- **Line** — net sales
- **Bars** — number of items sold

For one selected day, the graph shows sales by hour. For several days, it can show sales by day or week.

Select **Filter** to show or hide:

- YourFinds
- Pins
- Others
- Wholesale

Select or point to a part of the graph to see the sales and quantity for that time.

### Top selling items

This section shows which items sold the most.

You can sort by:

- **By qty** — highest quantity sold
- **By amount** — highest sales amount

You can also filter by category. Pins can be grouped by code, and YourFinds can be grouped by size.

### Payment breakdown

This section shows how customers paid, such as:

- Cash
- GCash
- Credit card
- QR Code

Select a payment method to see its total and its share of all payments.

## Reports you can open and download

Select a Dashboard card to open its report. Select the **download icon** to save the report as a PDF.

When the download icon is spinning, wait for the report to finish.

### Inventory Report

Shows:

- Current stock by category
- Item codes and descriptions
- Quantity available
- Sold-out, low-stock, and incomplete items
- Total pieces and wholesale bundles

Select **View inventory** to open the full Inventory page.

### Delivery Report

Shows:

- Items received during the selected date
- Item codes, descriptions, and quantities
- Total received per category
- Grand total
- Driver and plate number, when available

Select **View deliveries** to open the Deliveries page.

### Return Report

Shows:

- Items returned to the supplier
- Item codes, descriptions, and quantities
- Total returned per category
- Grand total
- Driver and plate number, when available

Select **View returns** to open the Supplier Returns page.

### Sales Report

Open this report by selecting **Net sales**.

It shows:

- Sales for each date
- Payment method or cashier breakdown
- Daily totals
- Grand total

Select **View transactions** to open the Transaction History for the same dates.

### Units Sold Report

Open this report by selecting **Units sold**.

It shows:

- Item code and description
- Price
- Quantity sold
- Sales per item
- Category totals
- Grand total

Select **View transactions** to open the Transaction History for the same dates.

### Transactions Report

Open this report by selecting **Transactions**.

It shows:

- Number of transactions per date
- Average sale
- Total sales
- Cashier totals — managers and OICs only

The downloaded PDF also shows receipt numbers, time, payment method, amount received, change, and sales. Only managers and OICs can download this detailed report.

## Dashboard reminders

- Make sure you selected the correct date before checking or downloading a report.
- Inventory always shows the current stock.
- Sales figures only include completed sales.
- Voided sales are not included.
- **No record** means there were no transactions for that date.
- A disabled download button can mean there is no data, you do not have permission, or the report is still loading.
- If you cannot see manager-only information, ask a Manager or OIC for help.
- Always sign out after using the POS.

# Cashier Page

The Cashier Page is used to add items, check the customer's cart, accept payment, and complete a sale.

## Before starting a sale

Cashier controls only work when you have an active cashier shift.

When starting a cashier shift:

1. Sign in using **Cashier** mode.
2. Check the petty cash amount you received.
3. Confirm the petty cash handover.
4. Start your shift.

The petty cash amount for your shift is shown at the top of the Cashier Page.

## Cashier Page sections

The page has two main sections:

- **Add items** — scan or search for products.
- **Shopping cart** — review items, quantities, discounts, and totals.

On a phone, use the **Add items** and **Cart** buttons to switch between these sections.

## How to add an item

### Scan a barcode

1. Select the **Scan barcode** box.
2. Scan the item's barcode. You can also type the code.
3. Press **Enter**.
4. Check that the correct item was added to the cart.

### Search for a product

1. Type the item name, size, or category in **Find a product**.
2. Select the correct item from the search results.
3. Select **Add to Cart**.

### Add a custom unlisted item

Use this only when the item is not listed in the inventory and your store procedure allows it.

1. Enter the item description.
2. Select the size. Choose **Custom** if you need to type another size.
3. Enter the price.
4. Select **Add Custom Item**.

Always double-check the name, size, and price before adding a custom item.

### Add a bundle

Some Pins, Others, and Wholesale products require a bundle code.

1. Add the bundle product to the cart.
2. Open the Cart.
3. Choose the correct bundle code before checkout.

Do not continue until every bundle in the cart has the correct code.

## How to check the cart

The Shopping Cart shows:

- Product image
- Product name
- Size
- Quantity
- Price
- Discount
- Line total

Before checkout:

1. Check every item with the customer.
2. Make sure the size and quantity are correct.
3. Make sure each bundle has the correct bundle code.
4. Check all discounts.
5. Check the Grand Total.

You can:

- Change an item's quantity.
- Apply a percentage or fixed-amount discount to one item.
- Select **X** to remove one item.
- Select **Clear cart** to remove the entire unsaved sale.

If the system warns that the requested quantity is higher than the available stock, stop and check the physical stock before continuing.

## Discounts and totals

### Item discount

Use the Discount fields on an item row to choose:

- Percentage discount
- Fixed-amount discount

### Global discount

Use **Global Discount** to apply one discount to the whole cart. Choose percentage or fixed amount, then enter the discount value.

The summary shows:

- Total items
- Subtotal
- Included 12% VAT
- Grand Total

Always confirm discounts and the Grand Total before taking payment.

## How to complete a normal sale

1. Review the cart with the customer.
2. Select **Proceed to Checkout**.
3. Choose the payment method.
4. Enter all required payment details.
5. Check the Total Due and Change Due.
6. Select **Complete Order** only once.
7. Wait for **Transaction complete** and the Receipt ID.
8. Give the correct change, if any.
9. Select **New Transaction** for the next customer.

Do not close or refresh the POS while a transaction is processing.

## Payment methods

### Cash

1. Choose **Cash**.
2. Enter the amount received from the customer.
3. Check the Change Due.
4. Give the exact change after the sale is completed.

### GCash

1. Choose **GCash**.
2. Enter the payment reference number.
3. Confirm that the payment was received before completing the order.

### QR Code

1. Choose **QR Code**.
2. Enter the payment reference number.
3. Check the total, including the displayed 1% fee.
4. Confirm that the payment was received before completing the order.

### Credit Card

1. Choose **Credit Card**.
2. Enter the payment reference number.
3. Check whether the 3.2% card fee should be added.
4. Confirm that the card payment was approved before completing the order.

### Split payment

Available combinations are:

- Cash + GCash
- Cash + Credit Card
- GCash + Credit Card

For a split payment:

1. Choose the correct combination.
2. Enter the amount for Payment 1.
3. Enter the amount for Payment 2.
4. Enter the required reference number for each non-cash payment.
5. Make sure the two amounts cover the total due.

## YourFinds down payment

A 50% down payment can be accepted for one available YourFinds item.

Rules:

- Only one stocked YourFinds item can be reserved at a time.
- The quantity must be 1.
- Custom items cannot be reserved.
- The down payment is non-refundable but can be used as exchange credit.

To create a reservation:

1. Add one eligible YourFinds item to the cart.
2. Apply any approved discount before the down payment.
3. Select **Down Payment (50%)**.
4. Complete the payment.
5. Give the customer the reservation Receipt ID and remaining balance.

To complete a reservation:

1. Make sure the current cart is empty.
2. Open **Transaction History**.
3. Find and open the reserved transaction.
4. Select **Complete Transaction**.
5. Collect the remaining balance and complete checkout.

## Transaction History

Select the clock icon beside **Add items** to open Transaction History.

You can:

- Search by barcode, receipt, cashier, or item.
- Filter by payment method.
- Open a transaction to see its items and payment details.
- View cash received and change for cash payments.
- See if a transaction was exchanged or voided.

Managers and OICs can also select a date range and view transaction summaries. Staff without an active cashier shift can view history, but cannot void, exchange, or complete a reservation.

## Customer exchange

1. Select **Exchange** on the Cashier Page, or open a transaction and select **Exchange**.
2. Enter the original Receipt ID and select **Search**.
3. Choose the original item being returned.
4. Select **Add Item** if more purchased items are being returned.
5. Choose the replacement product for each item.
6. Check the return and replacement quantities.
7. Add a reason or note when needed.
8. Select **Proceed to Checkout**.
9. Collect any additional amount due and complete the order.

Check the original item, replacement item, size, quantity, and price carefully before confirming.

## Void a transaction or item

Voids require manager authorization.

1. Select **Void**, or open the transaction in Transaction History and select **Void Transaction**.
2. Enter or confirm the Receipt ID.
3. If voiding one item, confirm the item code.
4. Ask the manager to authorize the action when required.
5. Choose the correct void reason.
6. If you choose **Other**, type the reason.
7. Select **Void Transaction** and wait for confirmation.

Never share or enter a manager PIN without the manager present.

## Cashier Shift Report

Select **Cashier Shift Report** at the top of the page to view or prepare your shift report.

The report can include:

- Verifying manager
- Report date
- Petty cash received
- Petty cash returned by bill and coin count
- Cash drawer count by bill and coin
- Petty cash difference
- Cash drawer remarks

If returned petty cash does not match the amount received, enter the petty cash voucher number and explanation.

Select **Compile & Download Shift PDF** when all information is complete.

## Pausing or ending a shift

When signing out from a cashier shift, choose the correct option:

### Pause shift

Use this when you will return and continue the same shift later.

- Return and count the petty cash.
- The shift remains available to resume later.

### End shift

Use this when your cashier work is finished.

1. Select the verifying manager.
2. Count the petty cash being returned.
3. Count all cash in the cash drawer by denomination.
4. Enter any required voucher information or remarks.
5. Review the totals carefully.
6. Tick the confirmation box.
7. Save the shift report.
8. Choose **Print report & sign out** or **Just sign out**.

The cash count must be true and complete. Explain every difference before ending the shift.

## Cashier reminders

- Confirm the item, size, quantity, discount, and total before payment.
- Confirm digital payments before selecting **Complete Order**.
- Record the correct reference number for every non-cash payment.
- Never complete the same order twice.
- Do not use another employee's cashier account.
- Ask a Manager or OIC if a price, stock warning, exchange, or void is unclear.
- Count all petty cash and drawer cash carefully before pausing or ending a shift.
- Always sign out when leaving the POS.
